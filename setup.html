Python Setup

MACRO Preceptor Training 27 · complete before Feb 3

← Course syllabus

Complete this setup before the Feb 3 class (week 2). It takes about 30–60 minutes, most of it waiting for downloads.

Before you start

When you're done, your computer will have three things:

  1. Miniforge, which installs Python and manages Python environments with a tool called conda.
  2. VS Code, the editor we'll use for Python scripts and Jupyter notebooks.
  3. The photometry environment, a self-contained Python setup with every package the course needs (astropy, photutils, ccdproc and others).

You'll need:

  • A computer running Windows 10/11, macOS, or Linux. Chromebooks and tablets (iPads, Android tablets) won't work; talk to Nathalie if that's all you have.
  • About 10 GB of free disk space in total, for the software plus the RLMT data you'll work with.
  • The file photometry.yml, posted on the course Discord.
  • A reliable internet connection for about 30 minutes.

If you already have Anaconda or Miniconda installed, skip Step 1 and use the conda you have. Don't install a second one.

Step 1: Install Miniforge

Miniforge gives you Python and conda, set up to download packages from conda-forge. Download page: conda-forge.org/download.

Windows

  1. Download Miniforge3-Windows-x86_64.exe and run it. If Windows warns you about the file, choose More info → Run anyway.
  2. Choose Just Me and keep the default install folder. Avoid folders with spaces or special characters in the path.
  3. Keep Create start menu shortcuts checked and accept the other defaults.
  4. When it finishes, open Miniforge Prompt from the Start menu. On Windows, this is where you type every conda command in this guide.
  5. In Miniforge Prompt, type conda init powershell and press Enter. This lets the terminal inside VS Code use conda later. Close Miniforge Prompt and open it again.

Mac and Linux

  1. Open Terminal (on a Mac: Applications → Utilities → Terminal).
  2. Copy and paste these two lines, pressing Enter after each:
curl -L -O "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-$(uname)-$(uname -m).sh"
bash Miniforge3-$(uname)-$(uname -m).sh

Copy each line exactly, quotes included, and run both in the same Terminal window. The $(uname) parts fill in your system automatically. Don't download the installer from the website instead: that file has a different name, and the second line won't find it.

  1. Press Enter to page through the license, then type yes to accept it.
  2. Press Enter to accept the default install location.
  3. When it asks whether to initialize conda ("conda init"), type yes. This is the important one.
  4. Quit Terminal completely and open it again.

Check it worked

In Miniforge Prompt (Windows) or a new Terminal (Mac/Linux), type:

conda --version

You should see something like conda 25.x.x. On a Mac, your prompt should also now start with (base).

Step 2: Install VS Code

  1. Download VS Code from code.visualstudio.com and install it.
    • Windows: accept the defaults. Checking Add "Open with Code" action is handy but optional.
    • Mac: open the downloaded file and drag Visual Studio Code into your Applications folder.
  2. Open VS Code and click the Extensions icon in the left sidebar (four small squares).
  3. Search for and install these two extensions, both published by Microsoft:
    • Python
    • Jupyter
  4. Make a folder for the course somewhere easy to find, such as Documents/MPT27. You'll keep your notebooks, scripts and data there.

Step 3: Create the photometry environment

  1. Download photometry.yml from the course Discord and save it in your course folder (for example Documents/MPT27).
  2. Open Miniforge Prompt (Windows) or Terminal (Mac/Linux).
  3. Move into your course folder with cd:
cd Documents/MPT27

On Windows, if your folder is somewhere else, type cd and then drag the folder into the window to paste its path.

  1. Create the environment:
conda env create -f photometry.yml

This downloads and installs everything, so it can take 10–20 minutes. Let it finish. Seeing lots of text scroll by is normal.

  1. Turn the environment on:
conda activate photometry

Your prompt should now start with (photometry) instead of (base). You need to run conda activate photometry each time you open a new terminal to work on course material. Inside VS Code, Step 4 sets this up for you.

Step 4: Use the environment in VS Code

VS Code needs to be told to use photometry rather than some other Python on your computer. Do this once per course folder.

  1. In VS Code, choose File → Open Folder… and open your course folder.
  2. Open the Command Palette: Ctrl+Shift+P (Windows/Linux) or Cmd+Shift+P (Mac).
  3. Type Python: Select Interpreter and press Enter.
  4. Pick the entry that says photometry (it will mention conda or miniforge3). If it's not listed, close and reopen VS Code and try again.

For Jupyter notebooks (.ipynb files): open or create a notebook, click Select Kernel in the top-right corner, choose Python Environments, then choose photometry.

For the terminal inside VS Code: open it with Terminal → New Terminal. If the prompt doesn't start with (photometry), type conda activate photometry. On Windows, if that gives an error, check that you ran conda init powershell in Step 1, then restart VS Code.

Step 5: Check that everything works

  1. In your course folder in VS Code, create a new notebook: Ctrl/Cmd+Shift+P → Create: New Jupyter Notebook.
  2. Select the photometry kernel (Step 4).
  3. Paste this into the first cell and run it with Shift+Enter:
import sys
import numpy, astropy, photutils, ccdproc, matplotlib
print("Python", sys.version.split()[0])
print("astropy", astropy.__version__, "| photutils", photutils.__version__)
print("You're ready for MPT27!")

If you see You're ready for MPT27!, you're done. Save the notebook as setup_check.ipynb, take a screenshot of the output, and post it in the course Discord.

If VS Code asks to install ipykernel, click Install. If you get a ModuleNotFoundError, the notebook is probably using the wrong Python: go back to Step 4 and select photometry.

Troubleshooting and getting help

ProblemFix
conda: command not found (Mac/Linux)Quit and reopen Terminal. If it still fails, run ~/miniforge3/bin/conda init and reopen Terminal.
conda not recognized (Windows)Use Miniforge Prompt from the Start menu, not the regular Command Prompt.
conda activate fails in VS Code's terminal (Windows)In Miniforge Prompt run conda init powershell, then fully restart VS Code.
photometry isn't in VS Code's interpreter or kernel listClose and reopen VS Code. Check conda env list shows photometry.
conda env create stops with an errorCopy the last 20 or so lines of the error and post them in Discord. Don't keep retrying.
A previous attempt half-finishedRun conda env remove -n photometry, then repeat Step 3.

Getting help: post in the course Discord with your operating system (Windows/Mac/Linux), which step you're on, and a screenshot or the copied error text. Error text is more useful than "it didn't work."
